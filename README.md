# APB RTL Design and Verification

## Overview

Designed and verified an APB interface using SystemVerilog RTL.

The APB Slave is implemented as a memory, and APB read/write
operations were verified using a SystemVerilog testbench.

## RTL Design

- APB Master
- APB Slave
- APB Top Module
- APB Slave implemented as memory
- APB read and write transactions
- APB Setup and Access phases

## Verification

- Verified APB write operations to the memory
- Verified APB read operations from the memory
- Checked correct data transfer between APB Master and memory-based Slave
- Verified APB protocol operation using a SystemVerilog testbench
- Analyzed simulation waveforms

## Tools

- Verilog
- SystemVerilog
- EDA Playground
